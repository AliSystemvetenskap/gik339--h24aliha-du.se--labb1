BILAL: Our second model is an enterprise architecture, using the four layers from TOGAF. It shows StarkFit after the One Member project. At the top, the business layer: members, gyms and staff, and the processes we just saw. Under it, the data layer: the main things the company needs to keep track of, like member, membership, gym, visit, class booking and payment. Then the application layer, with the member register in the middle, marked in orange, because every other application uses it: the app, door access, class booking, billing and reports. At the bottom, the technology layer: a cloud platform, an integration layer with APIs so old and new systems can talk to each other during the switch, the door controllers in the gyms, and the links to the bank and card provider. Each layer supports the one above it. This is the model we will build on in the coming labs.
